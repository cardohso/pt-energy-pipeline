About these numbers

A scheduled pipeline fetches the raw files, keeps every version, rebuilds the tables, and runs a quality gate before anything is published. If a blocking check fails, this page keeps showing the previous good build and says so above. Each headline number has a Trace button that lists the exact raw files it was computed from.
